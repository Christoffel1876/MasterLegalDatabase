Building Codes

Building Codes for all permits initiated on or after January 1, 2026

  • 2024 International Residential Code (IRC)
  • 2024 International Building Code (IBC)
  • 2024 International Energy Conservation Code (IECC)
  • 2024 International Existing Building Code (IEBC)
  • 2024 International Fuel Gas Code (IFGC)
  • 2024 International Mechanical Code (IMC)
  • 2024 International Plumbing Code (IPC)
  • 2024 International Property Maintenance Code (IPMC)
  • 2024 International Swimming Pool and Spa Code (ISPSC)
  • 2023 National Electrical Code (NEC)

2025 Wildfire Resiliency Code -  Effective January 1, 2026

The Board of County Commissioners unanimously adopted the 2025 Wildfire Resiliency code with Larimer County Amendments on September 22, 2025. 

2023 National Electrical Code - Effective August 1, 2023

The 2023 edition of NFPA 70 National Electric Code (NEC) was adopted by the State of Colorado and enforced by Larimer County, effective August 1, 2023.
