# Custody supports a fresh reviewed preparation

Custer `SHSTATE03-A024`, Delta `SHSTATE03-A014` + `SHSTATE03-A007`, and Costilla
`SHSTATE02-A012` have exact retained originals, reservation/result records, source
assignment/referral evidence and frozen independent delivery audits. Their hashes
were rechecked for this queue. There is no matching digest in the current 71-row
manual inventory. Delta and Costilla have matching legacy metadata rows; those
matches are preserved, not treated as newly discovered bytes or original-file
availability. No new HTTP request is needed merely to prepare custody intake.

These are received external review packages. Their worker HTTP/timing assertions
are available artifacts, not this auditor's direct observation. A prospective
record must keep the reported source URL/status/acquisition times separate from
the actual future local intake time. Final source-role and authority review is
still required, particularly where a filename/referral supplies the title. Delta's
code has 234 physical pages according to the prior independent parser; the
worker's original 236-page assertion must remain preserved with the correction.

The maintained generic `ManualSourceIntakeRequest` currently accepts only
`official_email`, `state_archives_request`, `manual_official_download`,
`public_records_request`, and `other_official_transfer`. It does **not** accept
`received_review_package`. It also derives `source_format` from the input suffix,
so passing these unchanged `.bin` paths directly would record `bin`, not PDF.
Neither assigning an inaccurate method nor silently renaming an original is a
valid shortcut. The generic function also updates the blocked queue, so it is not
the already-reviewed fixed-prefix transaction contract requested for recent
controlled intakes.

The accepted Gunnison preparation demonstrates an existing schema-compatible
fixed-source path: a strict subclass of `ManualSourceIntakeRecord`, explicit
`received_review_package`, null official URL, explicit PDF format, actual incoming
basename and separate reported acquisition evidence. It is a reference only. A
new copied/adapted preparation must bind these exact assets and IDs, fresh raw/
ledger/report prefixes, source and metadata schemas, custody sanitization, safe
partial recovery, and current runtime pins, followed by independent review before
application. Never run the historical transaction or use its frozen baseline.

The candidate can preserve the true `.bin` basename while explicitly establishing
PDF format from source bytes in a new typed plan, or create a separately documented
exact-byte input copy with its actual new basename. That choice belongs in the
new preparation. No copy or filename change was made by this queue audit.

The delivery packages contain private response headers. Do not publish the whole
delivery. Bind the exact public reservation/result/body joins and sanitized
provenance, retaining private originals separately. The current queue copies no
raw headers or source bodies. Custer's genuine A023→A024 chain is distinct from
the earlier rejected, semicolon-altered A017 request in the same delivery; the
latter does not invalidate or replace A024 and must not be silently repaired.
