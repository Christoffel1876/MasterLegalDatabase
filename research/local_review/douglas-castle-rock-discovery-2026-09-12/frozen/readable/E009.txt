Adopted Building Codes
Building and wildfire codes take effect this summer
Building Codes - Adopted amendments to the Town of Castle Rock Building Codes took effect June 30, 2026. The 2025 Colorado Wildfire Resiliency Code took effect July 1, 2026.
Building codes promote safety
The Town of Castle Rock has adopted the following building and fire codes for all new permit submittals.
See Title 15 of the
Municipal Code
for any specific exceptions to these codes adopted by the Town of Castle Rock.
2024 International Building Code
2024 International Residential Code
2024 International Plumbing Code
2024 International Mechanical Code
2021 International Energy Conservation Code
2024 International Fuel Gas Code
2024 International Fire Code
2024 International Existing Building Code
2024 International Swimming Pool and Spa Code
2017 ANSI A117.1
1997 Uniform Code for the Abatement of Dangerous Buildings
2026 National Electrical Code
ASME A17.1 2022 Elevator Code
ASME A18.1 2020 Safety Standard for Platform Lifts and Stairway Chairlifts
ASME A17.3 2023 Safety Code for Existing Elevators and Escalators
ASCE 21, Parts 1 through 4 Automated People Mover Standards
2025 Colorado Wildfire Resiliency Code
Model Colorado Electric Ready and Solar Ready Code
The subject matter of the codes concerns regulations to provide minimum standards to safeguard life or limb, property and public welfare by regulating and controlling:
Design
Construction and quality of materials
Use and Occupancy
Location and maintenance of all buildings, structures, plumbing systems and mechanical systems in the Town
