# Independent source-coverage review brief

This optional assignment can run alongside Geode's collection work. It asks for
independent source verification, without requiring repository write access.

## Assignment to share

Independently audit the official municipal-law source coverage for Golden and
Georgetown, Colorado. Start with the public Project Geode repository:
https://github.com/Christoffel1876/MasterLegalDatabase and its
`_CONTROL_PLANE/LOCAL_COVERAGE_LEDGER.json`. Use the latest source-recovery pull
request if it has not yet merged. Report the branch or commit you reviewed.

Find important official publications that the ledger does not yet preserve,
especially adopted ordinances after each consolidated code's cutoff, complete
fee schedules and later amendments, local building/fire adoptions, and official
district/service boundaries. Check the original sources; do not rely on another
model's summary or a search-result snippet.

For each finding return:

| Field | Required evidence |
|---|---|
| Authority and document | Exact name, ordinance/resolution number, and subject |
| Official source | Direct URL plus the official page linking to a delegated publisher |
| Version and dates | Code supplement cutoff, adoption, effective and posting dates separately; state unknown when absent |
| Evidence | Physical PDF page or HTML section and a short exact supporting passage |
| Relationship | What it expressly amends/repeals, and the cited predecessor source |
| Coverage gap | Missing document, incomplete text, unresolved amendment chain, or uncertain applicability |

Distinguish a downloaded code from a JavaScript catalog shell. Do not assume
that a live link proves current law, a water-fee amendment is the full fee
schedule, a county rule applies inside a municipality, or a district serves
a property because its mailing address names that city. Keep contradictory
fees or dates visible instead of choosing one without supporting authority.

Use ordinary public access and respect login, CAPTCHA and publisher restrictions.
Do not contact officials, pay for access, change the repository or change its
schedule. If an authorized export is needed, return the exact publisher page
and the visible export option. Do not publish temporary signed download tokens.

Return at most ten actionable, source-backed findings, ranked by likely impact
on accurate collection. Explicitly state what was checked and what remains
unverified. Geode will independently validate any proposed additions before
accepting them.
